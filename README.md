# Skyroute ✈️

An interactive, front-end flight booking web application built with React. Skyroute transforms a standard registration form into a cinematic experience using 3D scroll-driven animations and a modern glassmorphism aesthetic.

**[🚀 View Live Demo](https://skyroute-one.vercel.app)**

## ✨ Key Features

* **3D Scroll-Driven Animation:** A dynamic airplane that scales, translates, and flies into the digital sky smoothly as the user scrolls down the viewport.
* **Glassmorphism UI:** iOS-inspired translucent panels, frosted glass dropdowns, and buttons with backdrop-blur and responsive hover states.
* **Dynamic Time & Weather:** The environment adapts visually (clean morning sky vs. warm evening cabin lighting) based on real-world time.
* **Smart Form Logic:** 
  * Cascading selectors where City dropdowns strictly populate based on the selected Country.
  * Auto-cleanup state management that removes empty tickets from the dashboard if all seats are unassigned.
* **Interactive 3D Tickets:** Registered flight cards that dynamically tilt on mouse hover using CSS variables and math tracking.

## 🛠️ Tech Stack

* **Framework:** React.js
* **Styling:** Custom CSS3 (Glassmorphism, 3D Transforms, CSS Variables)
* **Deployment:** Vercel
